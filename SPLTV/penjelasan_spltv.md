PENJELASAN PROGRAM SPLTV

Program ini digunakan untuk menyelesaikan Sistem Persamaan Linear Tiga Variabel (SPLTV) menggunakan metode Eliminasi Gauss.

Tujuan

Menentukan nilai variabel x, y, dan z dari tiga persamaan linear.

Metode

Metode Eliminasi Gauss mengubah matriks augmented menjadi bentuk segitiga atas, kemudian menggunakan substitusi mundur untuk mendapatkan nilai setiap variabel.

Hasil Pengujian

Berdasarkan program yang dijalankan di Google Colab, diperoleh:

- x = 2
- y = 3
- z = -1

Kesimpulan

Program berhasil menyelesaikan SPLTV menggunakan metode Eliminasi Gauss.
