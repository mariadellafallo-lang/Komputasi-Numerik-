PENJELASAN PROGRAM BISECTION

Pengertian

Metode Bisection adalah metode numerik yang digunakan untuk mencari akar persamaan nonlinear dengan membagi interval menjadi dua bagian.

Tujuan

Menentukan nilai akar dari suatu persamaan nonlinear.

Metode

Program menggunakan fungsi f(x) = x³ - x - 2 dengan interval awal a = 1 dan b = 2. Nilai tengah dihitung menggunakan rumus:

c = (a + b) / 2

Proses diulang sampai memenuhi nilai toleransi.

Hasil Pengujian

Berdasarkan program yang dijalankan di Google Colab, diperoleh:

- Akar persamaan ≈ 1,52138
- Nilai f(c) mendekati 0.

Kesimpulan

Program berhasil mencari akar persamaan nonlinear menggunakan metode Bisection.
